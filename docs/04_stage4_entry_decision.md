# 阶段四准入决定

决定：**不准入多切片/整根立管阶段**。

准入前必须补齐：

1. 让 Ur=3–7 五个 SDOF 工况在低资源争用环境中各自完成固定流统计启动和稳定窗口；
2. 对至少锁定前、锁定中心、锁定后工况完成 dt/2、振幅、频率、相位、功率和能量平衡比较；
3. 将 ANCF 每步最小张力、最大斜率、最大曲率写入最终审计，并对持续负轴力给出 `compression-risk`；
4. 复核在线/解析升力相对差 `5.55%`，优先确认网格、初始流场、输出时间窗和力积分一致性；
5. 明确定义周期累计流体功和结构能量增量，重新给出归一化能量不平衡；
6. 只有在弱耦合时间收敛和能量平衡仍失败时，才实现每步 CFD/结构 checkpoint、固定松弛和 Aitken 强耦合。

当前不得宣称：多切片整根立管 VIV、曲线立管、工程高 Re 精度、ANCF 为大变形真值或 SDOF 已得到锁定曲线。
## 最新决定（2026-08-04）

不准入阶段四多切片。当前仅允许继续进行单切片闭环的restart、稳定统计窗口、EB/ANCF参数诊断及必要的Aitken强耦合实现；不允许将接口通过、近零响应或数值失稳结果宣传为整根柔性立管VIV验证。
