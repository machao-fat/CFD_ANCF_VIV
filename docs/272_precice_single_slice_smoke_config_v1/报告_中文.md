# Stage 272 单切片 preCICE smoke 配置准备

## 当前结论

`STAGE4F_D_PRECICE_SINGLE_SLICE_SMOKE_CONFIG_V1_GATE: pass`

本阶段只创建并校验隔离配置模板，不运行任何 participant 或 solver。模板固定了 Structure/Fluid 两个参与者、Structure-Mesh、Displacement/Force 数据、`coupling_dt=0.00125 s`、单切片和最多 8 步的 smoke 范围。

校验内容包括 XML 可解析性、OpenFOAM `preciceDict` 关键字段、ANCF participant 合同、单切片边界和 no-CFD/no-retry 守卫。所有离线检查通过，真实 MATLAB、OpenFOAM、WSL、CFD、preCICE participant 启动数均为 0。

模板采用独立的 `Structure-Mesh` 与 `Fluid-Mesh`：Structure 提供结构网格，Fluid 提供流体网格；位移使用 consistent nearest-neighbor 映射，力使用 conservative inverse 映射。Fluid 的 `preciceDict` 使用 `Fluid-Mesh`，避免在接收网格上错误写入载荷。

## 重要限制

这些文件位于 `tools/precice_adapter_v1/templates/single_slice_smoke`，不会被现有算例自动加载。`preciceDict` 中的 `cylinder` patch 和 mesh/data 名称仍需根据最终隔离 case 的实际边界字段做一次静态匹配；在匹配完成并取得新授权前，不得复制到运行 case 或启动 smoke。

下一步是对公开 `Validated-VIV` 隔离副本做只读字段审计，确认可用的耦合 patch、位移场和力场名称；确认后才具备申请一次真实单切片 smoke 的配置资格。
