# Stage 274 单切片 preCICE smoke 时间步修正

## 结论

`STAGE4F_D_PRECICE_SINGLE_SLICE_SMOKE_CONFIG_V2_GATE: pass`

你指出的疑问是正确的。公开 `Validated-VIV` / OpenFOAM 10 case 的 Stage 268 证据明确记录 `deltaT=0.005 s`、200 步对应 1 s。因此本公开 case 的第一版 smoke 配置不能使用旧 C++ worker 的 `0.00125 s`。

修正版固定：

- OpenFOAM CFD 步长：`0.005 s`；
- preCICE coupling window：`0.005 s`；
- smoke 范围：8 步、`0.04 s`；
- 单切片，接口网格 `Structure-Mesh`，patch `cyl`。

在实际 smoke 前，配置进一步收敛为单接口网格：Structure 提供 `Structure-Mesh`，Fluid 接收同一网格，暂不引入空间映射。这样可以先隔离验证 preCICE 生命周期和时间推进；非匹配 ANCF 网格映射另行验证。

`0.00125 s` 只有在未来隔离副本明确把 OpenFOAM `deltaT` 同步改为 `0.00125 s`，并重新完成独立数值资格验证时才可能使用；当前不能混用。

本阶段只修正和校验模板，没有复制到运行 case，也没有启动 MATLAB、OpenFOAM、WSL、CFD 或 preCICE participant。Stage 272 旧证据保持不变。
