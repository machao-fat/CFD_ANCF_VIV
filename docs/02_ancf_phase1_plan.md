# ANCF结构求解器阶段一实施计划

## 1. 目标

本计划的目标是把课题组提供的ANCF程序核心重构为可用于“直立顶张式柔性立管 + 二维CFD切片”的独立结构模块，并完成进入OpenFOAM闭环耦合前所需的物理、数值和接口验收。

本计划不要求阶段一完成OpenFOAM流场求解器，但要求结构模块可以接收切片运动和切片载荷，并且完成`H/H^T`传递、虚功和重启测试。

## 2. 当前基线

当前基线目录：

```text
src/structure_ancf_matlab/
tests/structure_ancf_matlab/
```

已完成：

- 直立底端到顶端的三维两节点ANCF梁；
- 每节点位置和斜率共6个自由度；
- Green型轴向应变和几何非线性曲率；
- 解析内力与解析切线；
- 一致质量矩阵；
- 重力、浮力和顶端轴向力；
- Newmark逐时间步推进；
- 切片运动输出；
- `H^T`外载荷传递；
- 小规模静力、动力和虚功测试。

当前版本仍属于MVP，尚未完成模态、自由振动、收敛性、低张力、旧程序对照和完整载荷回放验收。

## 3. 工作包与门槛

### WP0：冻结基线和可复现环境

任务：

- 记录MATLAB版本、源码目录和旧程序路径；
- 保留课题组原程序只读，不直接在原目录修改；
- 固定新模块的参数字段、坐标系和自由度顺序；
- 建立运行日志、测试结果和版本记录。

通过条件：

- 新旧代码路径明确；
- 任何测试可从MATLAB命令行重复运行；
- 原程序目录时间戳和内容不被新模块改变。

### WP1：结构物理模型完善

任务：

- 固定内部坐标为`+z`从底端指向顶端；
- 固定节点自由度顺序为`[r_x,r_y,r_z,r_{s,x},r_{s,y},r_{s,z}]`；
- 明确顶端横向导向、顶端轴向力和底端位置约束；
- 检查重力、浮力、质量、`EA`、`EI`单位；
- 重写张力和曲率输出，避免使用特定全局方向判断张力符号；
- 为结构阻尼和附加物理项保留明确接口，但不隐藏加入默认模型。

通过条件：

- 直立无载荷构型保持直线；
- 给定顶张力后静力张力沿立管连续；
- 输出张力单位为N、曲率单位为1/m、位移单位为m；
- 坐标和约束说明与`docs/01_interface_contract.md`一致。

### WP2：单元与整体数值验证

任务：

- 刚体平移和刚体转动零内力测试；
- 轴向拉伸与理论`EA*epsilon`测试；
- 纯弯曲/悬臂静力测试；
- 质量矩阵对称性和正定性测试；
- 解析切线与有限差分切线测试；
- 低阶模态测试；
- 无外载自由振动周期测试；
- 时间步收敛和单元数收敛测试。

通过条件：

- 刚体内力相对误差小于`1e-8`；
- 切线方向导数相对误差小于`1e-5`；
- 质量矩阵对称且最小特征值为正；
- 模态/自由振动误差有明确阈值并记录；
- 网格和时间步加密后核心指标达到预设收敛阶或给出解释。

### WP3：低张力和大变形验证

任务：

- 设置多个顶张力与有效重量比；
- 施加横向静力和简谐载荷；
- 输出最大斜率、位移比、曲率、轴向应变和张力波动；
- 检查低张力下负张力、构型翻转、切线病态和Newton不收敛；
- 建立“可计算区”和“物理/数值风险区”。

通过条件：

- 至少有高张力、中张力和低张力三组可复现算例；
- 不以“ANCF一定更准确”为先验结论；
- 对负张力和几何极端状态有明确处理策略；
- 能输出后续与传统梁比较所需的无量纲参数。

### WP4：CFD切片运动、载荷回放和守恒接口

任务：

- 输出切片位置、速度、加速度和参考弧长；
- 接收`n_slice × 3`的集成力或线力；
- 验证`Q_s=H^T F_f`；
- 完成随机虚功、功率、合力和力矩测试；
- 完成载荷回放和检查点重启一致性；
- 固定时间层语义和文件格式。

通过条件：

- `H`和`H^T`维度、排序、单位完全记录；
- 随机虚功误差小于`1e-10`量级；
- 集成力与线力两种输入的结果一致；
- 重启前后状态差异在数值容差内；
- 结构模块可不依赖OpenFOAM单独运行。

### WP5：旧程序对照和接力判断

任务：

- 选取相同材料、几何、单元数和边界条件；
- 比较质量、内力、切线、静态构型、曲率和张力；
- 明确旧程序中海床、波浪、尾流振子和平台运动不进入主线；
- 记录旧程序的可迁移函数和不迁移函数。

通过条件：

- 至少完成一个小型共同算例；
- 差异可以分解为坐标方向、边界条件、单位或公式差异；
- 不把旧程序结果直接当作新程序正确性的唯一证明。

### WP6：OpenFOAM前置接口包

任务：

- 提供一个可运行的结构主时钟示例；
- 写出`slice_motion`和`slice_loads`的CSV/JSON字段说明；
- 提供人工载荷回放示例；
- 规定OpenFOAM适配器不得重复加入Morison阻力和附加质量；
- 记录二维CFD到三维结构的力分量和轴向权重约定。

通过条件：

- 不接OpenFOAM也能完成接口测试；
- OpenFOAM只需替换载荷生产端即可接入；
- 传统梁对照可以复用同一载荷文件。

### WP7：最终报告和阶段门槛

最终报告必须包含：

- 结构模型、符号和单位；
- 代码目录与运行命令；
- 所有测试及误差；
- 低张力/大变形结果；
- 旧程序对照；
- `H/H^T`接口验收；
- 未完成内容、风险和进入OpenFOAM阶段的条件。

阶段一通过条件：

1. 结构模块可以独立初始化并逐步推进；
2. 直立顶张式边界条件和单位无歧义；
3. 单元、模态、自由振动、收敛性测试完成；
4. 至少三组张力工况可运行；
5. 载荷回放和`H^T`守恒测试完成；
6. 旧程序对照记录完成；
7. 传统梁和OpenFOAM仍可在下一阶段接入；
8. 所有未完成项均有明确的停止条件和替代方案。

## 4. 推荐顺序和止损

执行顺序固定为：

```text
WP0 → WP1 → WP2 → WP3 → WP4 → WP5 → WP6 → WP7
```

如果解析切线在大转动下出现异常，先停止低张力扫描，回到WP2的切线和能量测试；如果低张力下结构本身不收敛，不得通过减小时间步掩盖公式或边界问题；如果旧程序与新程序无法完全一致，优先保留新模块的清晰接口和可测试性，不把海床和平台功能重新带回主线。
