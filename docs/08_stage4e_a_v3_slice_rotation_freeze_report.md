# Stage 4E-A-v3：切片数量与双向坐标冻结候选

## 切片积分审计

误差相对于数字化速度剖面的高分辨率积分计算：

| 方案 | `∫U` | `∫|U|` | `∫U²` | `∫U|U|` |
|---|---:|---:|---:|---:|
| 均匀 5 | 1.717% | 0.503% | 2.948% | 4.784% |
| 均匀 7 | 3.226% | 0.634% | 0.046% | 0.671% |
| 均匀 9 | 1.952% | 0.714% | 0.286% | 0.768% |
| 优化非均匀 5 | 0.560% | 0.246% | 0.685% | 0.746% |

均匀 5 的 `∫U²` 误差为 2.948%，不通过 2% 冻结标准，不能直接冻结。优化非均匀 5 满足：

- `∫|U|` 误差：0.246%；
- `∫U²` 误差：0.685%；
- 简化 `∫U|U|` 误差：0.746%。

优化非均匀 5 的归一化边界为：

```text
[0, 0.13482, 0.33908, 0.53925, 0.81871, 1]
```

对应局部速度约为 `[0.4363, 0.4076, 0.0697, -0.1513, -0.1403] m/s`。该结果仍是速度剖面数字化基础上的离线设计，不是五切片 CFD 结果。

## 双向旋转合同

正向切片：

```text
R_GL = I
```

负向切片候选：

```text
R_GL = [[-1, 0, 0],
        [ 0,-1, 0],
        [ 0, 0, 1]]
```

该矩阵满足 `R^T R=I`、`det(R)=+1`，将局部 `+x` 映射到全局 `-x`，并将局部 `+y` 映射到全局 `-y`。100 组随机虚功检验最大相对误差为 0，未使用 `det=-1` 的反射矩阵。

## 冻结候选

在离线设计层面，建议将优化非均匀 5 切片作为最低成本候选，将均匀 7 切片作为保守备选。正式三切片 manifest、协议 0.2.1 和真实 CFD 配置均未修改。
