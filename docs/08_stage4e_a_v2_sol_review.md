## 2. 位移重构错误

原仓库 `main1.m` 的处理语义为：

```text
strain = raw_microstrain * 1e-6 * (D/D1)
A_jk = -R * (k*pi/L)^2 * sin(k*pi*s_j/L)
modal_displacement = pinv(A) * strain
displacement = Phi * modal_displacement
```

其中 `A` 已包含半径 `R`，因此解出的模态系数单位已是米，不能再除以 `R*1e6`。

现有 v2 实现存在两个错误：

1. 模态反演前未按原脚本乘 `D/D1`；
2. 位移重构后又除以 `R*1e6`。

另外，v2 中：

```python
cf_disp = cf_filtered / 1e6 * D / D1
```

实际仍是修正后的表面应变，不是位移，不得使用 `displacement` 命名。

因此 v2 的位移量级被人为缩小约 `R*1e6`量级，必须从原始应变重新生成。频率和模态阶次不受该常数缩放影响，可继续保留。

## 3. 结构网格决定

主 Agent 冻结：

- `nElem=8`：Umax=0.48 目标模态的最低可用结构网格；
- `nElem=16`：论文基准和后续多模态扩展的推荐参考网格；
- 暂不需要 `nElem=32`。

v2 的 H 探针 projector norm 并未做一致的物理幅值归一化，因此不单独用它作 Gate；频率簇、子空间主角和重构后的物理位移应作为正式指标。

## 4. 切片数决定

按既有判据：

- `int|U| ds` 误差不超过 2%；
- `int U^2 ds` 误差不超过 2%。

均匀 5 切片的 `int U^2 ds` 误差为 `2.948%`，因此不通过。当前证据支持的最小均匀划分是 7 切片。

Stage 4E-A-v3 允许设计零交叉区附近加密的非均匀 5 切片。若它同时满足两项 2% 判据和 5% 简化载荷积分判据，可将 5 切片作为最低成本方案；否则正式选用 7 切片。
