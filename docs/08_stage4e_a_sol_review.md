# Stage 4E-A Sol 主 Agent 复核

## 1. 判定

Stage 4E-A 判定为 `partially_accepted_correction_required`。文献调研、端木玉论文审计、结构参数重建和离线 ANCF 网格诊断有效，但存在湿频率证据遗漏、网格 Gate 定义不当和公开数据使用边界尚未关闭等问题。

主 Agent 决定：

1. `vivdatashare_bidirectional_shear_v048` 作为主基准进入“条件冻结”；
2. 它当前只用于离线数据管线、湿模态和参数映射，不授权真实 CFD；
3. Delft Delta 保留为文献图表级 fallback，不用它替代带原始 CSV 的主基准；
4. 不将“4/8 单元所有保留模态误差小于 1%”作为入口 Gate；
5. 网格收敛必须针对试验实际激发的目标模态，并对重根模态使用子空间 MAC/主角，不得用不同网格的最高离散模态直接比较；
6. 先完成 Stage 4E-A-v2 数据、元数据、湿频率和目标观测量闭环，再决定 Stage 4E-B。

## 2. 公开证据更正

Fu et al. 2022 双向剪切流柔性管试验文章明确给出：

- `L=7.64 m`；
- `D=28.41 mm`；
- 空气中单位长度质量 `1.24 kg/m`；
- `T=980 N`；
- `EI=58.6 N·m²`；
- `EA=9.4e5 N`；
- 阻尼比 `2.58%`；
- 水中实测前三阶频率 `1.59, 3.14, 4.78 Hz`；
- 计算第一水中频率 `1.51 Hz`；
- 水密度 `1000 kg/m³`；
- 附加质量系数 `Cm=1.0`。

因此原 Stage 4E-A 中“公开实验湿频率不可用”的结论不成立。现有 ANCF 干频率约 `1.84812 Hz`，使用 `Ca=1.0`、`rho=1000 kg/m³` 的附加质量估计约为 `1.503 Hz`，与论文计算值 `1.51 Hz` 相符，但与实测 `1.59 Hz` 仍应分别保留。

源类型应更正为：

- Fu et al. 2022, JFS 114, 103722：主试验论文；
- Fu et al. 2025, Marine Structures 104, 103895：条带 CFD/FEM 数值验证论文；
- VIVdatashare：精选原始应变数据和数值代码仓库。

## 3. 数据许可边界

仓库当前未见显式 LICENSE。主 README 表示实验数据在协商后可用，实验子目录说明当前上传的是合同允许共享的精选原始应变数据。因此：

- 可对公开 CSV 进行内部学术复核和可重复数据管线开发；
- 暂不将原始 CSV 再分发到本项目或论文附件；
- 论文正式使用前应向作者确认引用、衍生结果发布和原始数据复现边界；
- Stage 4E-A-v2 只可产生联系邮件草稿，不得自行发送。

## 4. 网格收敛更正

对 VIVdatashare 参数模型：

- `nElem=4/8` 低阶目标模态已满足 2% 频率诊断和 MAC 条件；
- `nElem=8/16` 当前记录的前八个频率最大差约 `0.55%`；
- “4/8 所有保留模态差异 8.36%”不应单独阻塞基准选择。

Stage 4E-A-v2 必须先从 `Umax=0.48 m/s` 试验数据识别实际主导模态，再对这些模态使用频率、模态子空间 MAC 和切片 H 运动收敛冻结 `nElem`。
