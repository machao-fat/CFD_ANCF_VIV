# Stage 4F-A 低 Re 无量纲基准设计停止报告

## 结论

Stage 4F-A 在结构反设计开始前触发硬停止条件 5：冻结的三个 `β` 候选均不满足 `T/EA ≤ 1%`。因此未选择生产结构候选，未启动 MATLAB 或 OpenFOAM，也未冻结 3/5/9 切片协议身份。

## 已核对的低 Re 合同

- `D=1 m`，`U=1 m/s`，`rho=1000 kg/m³`，`nu=0.01 m²/s`；
- `Re=UD/nu=100`；
- `L=10D=10 m`；
- `St=0.15–0.18`，对应参考脱涡频率 `0.15–0.18 Hz`；
- `Ur1=5.5`，对应目标第一湿频率 `f1=1/(5.5D)=0.1818181818 Hz`；
- `d_i/D=0.9`，`Ca=1`，阻尼比 `ζ=0.01`。

参考脱涡频率仅用于调谐设计，不是耦合后频率，也不构成 VIV 预测。

## 硬停止推导

任务书同时规定

```text
β = EI/(T L²)
EI = E I
EA = E A
```

按要求由 `β` 和 `T` 反求同一材料模量 `E`，则

```text
EI = β T L²
E  = β T L²/I
EA = β T L² A/I
T/EA = I/(β L² A)
```

圆环截面为

```text
A = π(D²-d_i²)/4 = 0.14922565104551513 m²
I = π(D⁴-d_i⁴)/64 = 0.016881151774523904 m⁴
```

因此

```text
I/(L²A) = 0.00113125
```

| β | T/EA | 百分比 | `≤1%` |
|---:|---:|---:|:---:|
| 0.001 | 1.13125 | 113.125% | 否 |
| 0.01 | 0.113125 | 11.3125% | 否 |
| 0.05 | 0.022625 | 2.2625% | 否 |

该比值与质量比、目标频率和反求张力无关，所以 `m*={2,5,10}` 的全部九个组合都会失败。继续反求张力、运行特征值或调合成载荷不能改变这一结论。

## 未采用的规避方式

- 未放宽 `T/EA≤1%`；
- 未增加 `β` 候选；
- 未改变 `d_i/D=0.9`；
- 未把轴向模量与弯曲模量静默解耦；
- 未用 CFD 结果反向拟合。

若坚持当前几何与单一材料模量，要满足 `T/EA≤0.01`，至少需 `β≥0.113125`，超出允许集合。该数值只用于解释不可行性，不是新增候选建议。
