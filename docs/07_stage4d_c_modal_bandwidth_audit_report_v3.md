## 6. 7.13% 切片速度误差归因

报告保留 Sol 冻结的 v2 最细相邻对切片速度 NRMSE `0.0712641380`。同时，v3 严格按照共同物理时间戳匹配粗细时间序列，不插值、不相位平移，重新计算得到 `0.0831320236`。原因是每个回放数组从各自第一个时间步开始，v2 原始比较使用了不同时间网格的首元素对应关系。该差异作为证据审计问题记录，不覆盖 Sol 冻结值。

严格时间戳对齐结果：

| 相邻步 | 全模态切片速度 NRMSE | 模态1–2累计 | 模态6及以上累计 | 模态1–2截断相对全细步误差 |
|---|---:|---:|---:|---:|
| 0.0025 / 0.00125 | 0.32901 | 0.32532 | 1.22790 | 4.05% |
| 0.00125 / 0.000625 | 0.13612 | 0.12161 | 1.33628 | 4.60% |
| 0.000625 / 0.0003125 | 0.08313 | 0.04391 | 1.29781 | 5.44% |

模态3–5在切片速度中几乎没有幅值贡献；第6–7模态贡献很小的位移和动能，但合计约 4.85% 的绝对外力做功，并使模态1–2截断的切片速度重构误差达到 5.44%。因此：

1. 前三阶模态收敛并不足以保证切片速度收敛；
2. 高阶模态确实对切片速度和做功有实际贡献，但主要可见的是第6–7模态，不是第3–5模态；
3. 严格对齐的总速度误差仍主要受前两阶低频模态相位差影响，不能把全部误差归因于高阶模态；
4. v2 的 7.13% 指标与当前时间网格对齐方式存在差异，Sol 应在后续 Gate 中决定采用哪个可复现定义。

最大五个 leave-one-mode-out 误差变化中，模态1、模态2、模态7、模态6最显著；模态3–5不构成主要速度误差来源。

对最细已有 release 回放按频率逐步累加模态，采用四个同时条件：位移质量范数 ≥99%、动能 ≥99%、切片速度 RMS 重构误差 ≤1%、绝对做功 ≥99%。

最小满足条件的候选为模态 1–7，最高频率 `302.8969161 Hz`：

- 位移质量贡献：`0.9999999999989702`
- 动能贡献：`0.9999999999977683`
- 切片速度 RMS 重构误差：`3.63e-16`
- 绝对做功贡献：`0.9999999999999999`

只保留模态1–2时，位移质量和动能已接近 99%，但切片速度 RMS 重构误差仍为 `5.4419%`，绝对做功仅 `95.147%`。因此 1–7 是满足本任务候选规则的工程带宽候选，但状态为“候选、未冻结”，不能由 Luna 单方面冻结为生产带宽，也不能降低既有 5% 时间步 Gate。

## 8. 当前最细步是否在有效贡献频带收敛

不是。第6–7模态属于工程带宽候选，并且有可见速度/做功贡献；但在 `dt=0.0003125 s` 下其 Newmark 累计相位误差约为 `-13.324 rad`，远大于 `0.05 rad`。因此当前最细已有步仅对第一低频模态相位较好，对具有实际做功贡献的高频模态尚未达到理论相位收敛。

## 9. 结论边界

本报告证明的是模态重构、H/Hᵀ守恒、工程带宽候选和时间色散尺度。它没有证明长期 VIV、锁定区、稳态振幅或物理参数有效性，也没有授权新的真实 CFD。
