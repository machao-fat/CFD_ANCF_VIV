# 单自由度自由 VIV 验证

SDOF 方程为 `m y'' + c y' + k y = Fy`，Newmark 平均加速度由 `src/coupling/sdof/` 实现。参数固定为 `Re=100`、`m*=m/[rho*pi*D^2/4]=10`、`zeta=c/(2*sqrt(k*m))=0.01`、`Ur=U/(fn D)`，五个工况为 `Ur=3,4,5,6,7`。因此 `fn=1/Ur Hz`；固定圆柱 `St≈0.16` 时锁定中心预期在 `Ur≈6.25` 附近。

选择该低 Re 参数范围是为了与现有二维 CFD 对齐；公开 Re=100 数值研究也采用 `m*=10、zeta=0.01` 并讨论锁定区和能量传递，例如 [AIP 公开论文](https://doi.org/10.1063/5.0056162)。本项目只借鉴参数定义和锁定判据，不声称复现该论文的全部网格、边界和数值设置。

每个工况独立运行固定流启动、逐步在线运动、压力/黏性/总力、瞬时功率、累计流体功、阻尼耗散和运动历史。只有五个工况都达到统计稳定、时间步减半不改变趋势，才把 SDOF 项标记为通过。
