# Stage 273 公开 OF10 case 与 preCICE FSI 兼容性审计

## 结论

`STAGE4F_D_PRECICE_PUBLIC_CASE_COMPATIBILITY_V1_GATE: do_not_pass`

只读审计确认公开 case 的圆柱 patch 名为 `cyl`，模板已同步修正为 `cyl`。但当前 case 的 `0/pointDisplacement` 中 `cyl` 类型为 `calculated`，不是 adapter FSI 位移耦合要求的 `fixedValue`；`dynamicMeshDict` 使用 `rigidBodyMotion`，没有 `displacementLaplacian`。因此不能直接把 preCICE `preciceDict` 放入公开 case 运行。

下一步需要在全新隔离副本中完成 mesh-motion 和边界条件适配，再做静态字典校验。公开 case 本身保持只读，未启动任何 solver。

本阶段 MATLAB、OpenFOAM、WSL、CFD 和 preCICE participant 启动数均为 0。Stage 1--272 证据、ANCF/EB 核心和物理参数未修改。
