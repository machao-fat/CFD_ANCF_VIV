# Stage 4E-A-v3：位移量纲修正与观测量闭环

## 状态

本报告是独立 v3 离线结果，不修改 v2 目录或证据，不启动任何 CFD。

v2 的位移量纲证据已由 Sol 复核作废：反演前缺少 `D/D1`，重构后又错误除以 `R*1e6`。v3 使用：

```text
epsilon_j(t) = raw_microstrain_j(t) * 1e-6 * D/D1
A_jk         = -R*(k*pi/L)^2*sin(k*pi*s_j/L)
q(t)         = pinv(A)*epsilon(t)
y(s,t)       = Phi(s)*q(t)
```

其中 `epsilon` 无量纲、`A` 单位为 `1/m`、`q` 和 `y` 单位为 m。`R`、`D/D1` 和 `1e-6` 均只使用一次。

## 制造解

CF 9×8 和 IL 14×13 制造解均通过：

| 类别 | q 相对误差 | y 相对误差 |
|---|---:|---:|
| CF | `2.32e-15` | `2.33e-15` |
| IL | `1.06e-14` | `1.06e-14` |

未使用逆后 `R` 或 `1e6` 缩放。

## U=.48 m/s 修正观测量

当前项目处理协议选择四阶零相位 Butterworth、0.01–20 Hz。该协议不是作者 `bpass.m` 的严格复现。

| 方向 | 沿程 RMS 最大值 | 全局峰值 | 峰值位置 | 最大 A/D |
|---|---:|---:|---:|---:|
| CF | `6.965e-3 m` | `1.834e-2 m` | `4.0492 m` | `0.6456` |
| IL | `1.548e-3 m` | `6.477e-3 m` | `1.9482 m` | `0.2280` |

目标模态结果：

- CF mode 1：RMS `6.821e-3 m`，主频 `1.5564 Hz`；
- IL mode 2：RMS `1.240e-3 m`，主频 `3.2959 Hz`；
- IL mode 4：RMS `8.177e-4 m`，主频 `6.6223 Hz`。

以上数值全部由 v3 重新从原始微应变重构，不继承 v2 位移结果。
