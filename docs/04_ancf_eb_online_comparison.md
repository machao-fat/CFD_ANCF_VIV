# ANCF/EB 同工况在线比较

比较使用独立 CFD 目录，但共享网格、物性、时间步、切片位置、初始流场、结构几何、质量、EI、预张力和阻尼。比较量包括位移 RMS/峰值、主频、力 RMS、瞬时功率、结构能量、预测—校正残差和计算成本。

当前 1000 步高张力接口诊断结果：EB 与 ANCF 的校正位移最大绝对差约 `2.25e-10 m`，公共时间段 1000 步；力相对 RMS 差约 `5.6%`，超过严格 5% 门槛的边缘，须结合时间步减半和更有物理意义的柔性配置复核，不能立即归因于几何非线性。机器可读汇总位于 `results/04_ancf_eb_online_comparison/ancf_eb_online_comparison.json`。
