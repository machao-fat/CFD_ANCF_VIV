# 阶段四准入决定（修复后）

决定：**不准入多切片/整根立管阶段**。

准入前必须完成：

1. 严格 native/file 案例中途 restart 前后逐步力、U/p、网格点和时间索引差分；
2. Ur=5.2、6.0、4.0、7.1、8.0 每个至少 10 个稳定结构周期，形成 `A/D–Ur`、`f/fn–Ur`，并与 Tang 2DOF 参照明确区分；
3. 至少锁定前/中心/后工况完成 dt/2，统一物理时间窗；
4. 运行修复后的 EB/ANCF 同工况在线案例，响应必须显著高于数值容差；
5. 使用显式 `W_CFD/W_structure/E_defect/ΔE/W_damping` 完成稳定窗口能量审计；
6. 记录长期网格质量、CFL、张力和压缩风险；
7. 依据残差、added-mass、能量和 dt 收敛证据决定是否进入固定松弛/Aitken。

当前仅允许继续做单切片和单自由度诊断，不允许把它们解释为多切片整根柔性立管 VIV 验证。
## 最新入口决定（2026-08-04）

决定不变且更加明确：**不具备进入多切片/整根立管阶段的资格。**

原因是 SDOF 尚未形成稳定锁定趋势，dt/2 关键量变化超过目标，EB/ANCF 尚未完成可见稳定响应下的独立在线比较，严格 A/B restart 及长时间能量/网格审计也未闭合。当前可继续的范围仅限于单切片接口、runner、restart、能量定义和强耦合诊断；不得把近零响应或CFL失稳结果解释为物理结论。
