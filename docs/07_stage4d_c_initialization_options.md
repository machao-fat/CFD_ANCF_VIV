# Stage 4D-C-A-v2 初始化路线离线对照

## 1. 范围

本文只比较 ANCF 结构单独计算中的两种初始化路线，不改变正式 persistent worker，不改变 OpenFOAM 网格，不生成新的 CFD case，也不重新暖机。

- **release**：静态水动力为零，完整 `F_i(t)` 从动态耦合起始时施加。
- **preload**：用快照末端初始积分力 `F_i(0)` 求水动力预载静力平衡，再以 `ΔF_i(t)=F_i(t)-F_i(0)` 施加增量载荷。

preload 仅离线调用 `ancf_initialize` 与 `ancf_advance_step`。它没有通过修改 persistent worker 来实现，也没有将 `F_i(0)` 和完整 `F_i(t)` 重复加入。

## 2. 预载静力结果

两条路线都使用相同的 ANCF 参数和零初速度、零初加速度。静力求解均收敛于 8 个载荷增量、104 次 Newton 迭代：

| 路线 | 初始残差 | slice 0静力位置 (m) | slice 1静力位置 (m) | slice 2静力位置 (m) |
|---|---:|---|---|---|
| release | 0.005112841725349426 | `(0,0,0)` | `(0,0,5.001613517473474)` | `(0,0,10.003229941083585)` |
| preload | 0.005106369033455849 | `(0,0,0)` | `(1.9370013671081342e-5,4.96579913532679e-7,5.001613517430496)` | `(0,0,10.003229940997631)` |

初始 `qdot` 和 `qddot` 均为零。preload 造成的 slice 1 横向静力偏移约 `1.94e-5 m`，表明它不是纯粹的数值标签变换，而是改变了动态计算的参考构型。

## 3. 28 Hz 启动振铃

下表为 0–0.05 s 窗口中 27.509 Hz 分量幅值；三项依次为 slice 0、slice 1、slice 2，单位 m。

| dt (s) | release | preload |
|---:|---|---|
| 0.0025 | `(0, 4.3349e-7, 0)` | `(0, 6.7569e-8, 0)` |
| 0.00125 | `(0, 1.0063e-6, 0)` | `(0, 8.5667e-7, 0)` |
| 0.000625 | `(0, 1.0351e-6, 0)` | `(0, 8.6111e-7, 0)` |
| 0.0003125 | `(0, 1.0468e-6, 0)` | `(0, 8.6174e-7, 0)` |

在细步区间，preload 的 28 Hz 启动幅值约比 release 低 15–18%；但粗步值受采样和初始载荷阶跃影响，不能单独作为路线优越性的证据。release 与 preload 的全动态状态和速度误差也不是同一参考构型下的简单替代关系。

## 5. 路线选择约束

回放相邻时间步推荐阈值要求同时满足切片位移、切片速度、主要模态速度、主要模态加速度及峰值/RMS条件。release 的三组相邻对均至少在切片速度 NRMSE 上失败；preload 的三组相邻对也均失败，主要问题是速度/加速度一致性。因此两条路线当前均输出：

```text
recommended_release_real_dt_pair = none
recommended_preload_real_dt_pair = none
```

这不等同于证明任一路线的物理模型错误，而是说明现有 0.25 s 载荷回放与给定的严格速度/加速度推荐规则尚未给出可直接授权的新真实 CFD 时间步。

## 6. 后续由 Sol 决定的接口问题

若选择 release，应由 Sol 决定是否以更细真实 CFD 时间步建立新基准，并重新审查高频模态、力时间分辨率和计算成本。

若选择 preload，应先正式设计：快照初始力的来源、三切片静力平衡与 CFD 初始网格的一致性、初始 `motionScale`/points 身份以及 restart 语义；完成这些协议冻结后才能建立新的真实 campaign。

本离线对照未批准任何阻尼，也未批准修改正式 worker。
