## 4. 不批准直接进入长时间物理计算

Stage 4C-B通过不代表长时间三切片VIV已经具备生产准入，原因如下：

1. ANCF当前由每次启动MATLAB的batch wrapper调用真实核心，短时结果有效，但长时间计算的进程启动成本不可接受；
2. OpenFOAM当前每个slice-step重新启动进程，尚未完成长时效率和资源评估；
3. 代码中的最大并发数目前固定报告为1，没有信号量或运行时并发计数器强制上限；
4. `t0=0.05 s` 的预热远短于Re=80–120圆柱典型涡脱落时间尺度，当前力属于启动瞬态，不能用于锁定区或VIV统计；
5. 当前只有3个耦合步，尚未证明弱耦合长期稳定性、能量收敛或统计平稳。
