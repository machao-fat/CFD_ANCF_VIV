# Stage181 C++ worker 全面审查与修复报告

## 结论

本阶段确认并修复了 MSVC 异常展开配置缺陷和 Windows 二进制流设置错误处理缺陷。Stage181 构建、静态分析、专项测试、非零 base_load ownership 双算和根目录回归均通过。

Gate：`STAGE4F_D_CPP_WORKER_COMPREHENSIVE_AUDIT_REPAIR_V1_GATE: do_not_pass`。唯一硬阻断仍是 MATLAB/C++ 严格数值等价：现有证据为工程 replay 40/40，但 strict dual 0/40，首个失败 step=560，因此不能标记 C++ 数值核心 validated。

## 修复

- 将 `/EHsc` 放在 CMake target 声明之前，确保所有 MSVC worker target 生成 `ExceptionHandling=Sync`；
- 三个 Windows worker 检查 `_setmode(stdin/stdout, _O_BINARY)` 返回值，失败立即退出；
- 增加 CMake 顺序契约测试。

未修改 ANCF/EB 物理语义、物理参数、global dt、slice 数、数值阈值、统计门槛、正式 0.2.1 协议或旧证据。
