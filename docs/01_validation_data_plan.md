# 公开试验数据与验证计划

## 1. 选择结论

- **主要试验：Chaplin/Southampton 直立张紧立管阶梯流试验（DHL03）。**
- **备用试验：MIT–DeepStar Miami II Gulf Stream 长柔性管试验。**
- NDP 38 m 均匀/线性剪切流和 VIVdatashare 双向剪切流只作为补充，不作为阶段二启动的默认数据源。

主要试验与本课题的直立顶张、阶梯/剪切共线流、IL/CF、不同张力和曲率验证高度一致，并且已经被 viv-FOAM-SJTU 与 viv3D-FOAM-SJTU 用作基准。Miami II 的高模态、行波和真实剪切流更复杂，适合在主线通过后检验外推能力。

## 2. 主要试验：Chaplin/Southampton DHL03

### 2.1 试验与论文

论文：[J. R. Chaplin, P. W. Bearman, F. J. Huera Huarte, R. J. Pattenden, “Laboratory measurements of vortex-induced vibrations of a vertical tension riser in a stepped current,” Journal of Fluids and Structures 21 (2005) 3–24](https://doi.org/10.1016/j.jfluidstructs.2005.04.010)。盲算比较见 [Chaplin 等（2005）](https://doi.org/10.1016/j.jfluidstructs.2005.05.016)。

关键试验参数：

- 直径 `D = 0.028 m`；
- 长度 `L = 13.12 m`，`L/D ≈ 469`；
- 质量比约 3.0；
- 下部约 45% 暴露于均匀流，上部处于静水；
- 车速最高约 `1.0 m/s`；
- 由 32 个等间距应变站重建 IL/CF 响应；
- 不同系列改变上下端张力和真空管状态。

### 2.2 数据文件和测量量

MIT 库的官方说明为 [DHL03-VIV-database-notes.pdf](https://mit-viv-database.mit.edu/files/2025/07/DHL03-VIV-database-notes.pdf)，2022-03-09 版本。每个 `DHL03_SnnRmm.csv` 包含：

| 列 | 内容 | 单位 |
|---|---|---|
| 1 | 时间 | s |
| 2–33 | 32 个站位的 IL 曲率，从底到顶 | 1/m |
| 34–65 | 同一站位的 CF 曲率 | 1/m |
| 66 | 车速 | m/s |
| 67–68 | 底端、顶端张力 | N |
| 69 | 距底端 3.44 m 的内部 y 加速度 | m/s2 |
| 70–71 | 距底端 5.59 m 的内部 x/y 加速度 | m/s2 |
| 72 | 底端阻力 | N |
| 73 | 原始文件名 | - |

首个应变站距底端 0.205 m，相邻站间距 0.410 m。系列 10–12 的顶端张力传感器失效，使用这些系列时不能把缺失顶张力当成零或常值。

### 2.3 建议使用的系列

下载后按 CSV 中实测车速匹配试次，不只依赖 `Rmm` 顺序。

| 用途 | 系列 | 静水底/顶张力（N） | 作用 |
|---|---:|---:|---|
| 中等张力基准 | S03 | 629 / 813 | 与 S02 条件近似但水面更平静；用于 CFD–线性梁基线和数值设置冻结 |
| 高张力对照 | S05 | 1356 / 1546 | 检查线性梁与 ANCF 在小几何非线性区是否趋同 |
| 低张力锚点 | S06 | 214 / 389 | 检查明显构型/张力波动下模型差异；不是唯一低张力结论来源 |
| 细速度扫描 | S15 | 629 / 813 | 0.4–1.0 m/s、约 0.01 m/s 步进；用于锁定区间和模态转换，不用于参数逐点调优 |

S06 数据张力较低，但仍须用实际位移斜率和张力波动判断几何非线性，不能只凭系列标签宣布线性梁失效。

### 2.4 获取方式、密码和版权

MIT [Datasets 页面](https://mit-viv-database.mit.edu/datasets-2/)公开列出 “John Chaplin – SouthamptonU Dataset”，但下载入口明确标注 **PASSWORD-PROTECTED DOWNLOAD ACCESS**。README 可以直接访问，原始/处理后 CSV 需要向页面所列联系人申请密码。

2. 保存许可邮件、数据版本、下载日期和 checksum；
3. 原始文件存 `data/raw/chaplin_dhl03/`，只保存本地，不提交公共 Git；
4. `data/processed/` 可保存自行生成的统计量，但公开前确认衍生数据许可；
5. 论文引用原论文、数据说明和数据库页面，不把“可申请”写成“完全开放下载”。

### 2.5 数据处理流程

1. 保留原 CSV 和 SHA-256，不改写原文件；
2. 检查时间单调、采样间隔、非有限值、张力传感器状态和列数；
3. 依据车速时序划分稳态窗，记录剔除初始过渡的规则；
4. 直接以曲率作为首要观测量，避免位移重建引入不必要误差；
5. 若需要位移，用论文/README 的边界条件和模态最小二乘方法重建，并通过加速度和曲率交叉检查；
6. 输出每工况 IL/CF 曲率 RMS 包络、PSD、主频、模态权重、平均/波动张力、底端阻力；
7. 同一处理脚本用于试验、线性梁和 ANCF 结果。

## 3. 备用试验：MIT–DeepStar Miami II

### 3.1 试验与可用内容

MIT 官方试验页：[Gulf Stream Test Overview (Miami II)](https://web.mit.edu/shear7/experiments.html)。代表论文：[Vandiver, Jaiswal, Jhingran, “Insights on vortex-induced, travelling waves on long risers,” Journal of Fluids and Structures 25 (2009) 641–653](https://doi.org/10.1016/j.jfluidstructs.2008.11.005)。

2006 年试验在 Miami 近海 Gulf Stream 进行，使用约 500.4 ft（152.4 m）长、1.43 in（36.3 mm）外径的复合管，由底部重物张紧。密集光纤应变测量可解析高阶模态和行波。官方 `miami-data-ReadMe.pdf` 说明数据包包括：

- 两套 ADCP 的原始/`.mat` 流速剖面；
- 推荐 benchmark cases（`.mat`），含改进的法向入流速度估计；
- 按裸管、部分/全部整流罩或扰流条配置组织的处理后 `.mat` 数据；
- 报告、附录和相关文章；
- National Instruments 的流速计、深度、载荷和倾角数据；
- 光纤制造扭转修正和已知问题清单。

README 同时说明处理后数据含各变量的 `ReadMe`，而原始应变因容量限制未包含在常规 `Data` 目录。建模时必须读取每个 `.mat` 内部的变量说明，不能根据名称猜测。

### 3.2 为什么只作为备用

- 真实 Gulf Stream 流速大小和方向沿深度变化，超出主线固定共线二维切片的理想条件；
- 长度和模态数显著高于 Chaplin，切片数量和总成本更高；
- 行波、结构扭转、法向入流重建和高阶谐波使后处理更复杂；
- 数据同样在 MIT 数据库的 password-protected 区域，需要联系 J. Kim Vandiver；未见允许随代码仓库再分发的开放许可证。

因此 Miami II 的最小用途是选一个官方 benchmark bare-pipe case，比较 CF/IL 应变谱、主模态和空间包络；不在硕士主线中复现所有抑振配置。

## 4. 其他数据源的地位

### 4.1 NDP 38 m

[Trim 等（2005）](https://doi.org/10.1016/j.jfluidstructs.2005.07.014)报告 38 m、`L/D≈1400` 的均匀/线性剪切流试验，含 IL/CF 应变和加速度，适合高模态扩展。但公开论文并不等于数据拥有开放再分发许可；需通过 MIT VIV 库或权利方确认访问条件。

### 4.2 Hanøytangen 90 m

[Lie 和 Kaasen（2006）](https://doi.org/10.1016/j.jfluidstructs.2006.01.002)报告 90 m、3 cm 直径、29 个双向弯矩站和高模态剪切流响应，特别适合验证模态重建和高阶响应。数据权限和模型复杂度使其暂列文献对照。

### 4.3 VIVdatashare 双向剪切流

GitHub 目前可见选定原始应变 CSV 和 MATLAB 处理代码，对应 [Fu 等（2022）](https://doi.org/10.1016/j.jfluidstructs.2022.103722)。但仓库无明确许可证，README 说明分享受合同限制，因此只可在本地合规阅读/运行和引用；除非作者授权，不把原始数据或代码复制到本项目。

## 6. 校准、验证和接受标准

### 6.1 数据隔离

- **校准集**：静水固有频率、一个 S03 中等速度工况，用于结构阻尼和数值参数；
- **内部验证集**：S03 的其余速度，不再逐工况调参；
- **外部验证集**：S05 与 S06，检验张力变化下模型泛化；
- S15 细速度扫描用于观察锁定/模态转移，不能把每个速度点单独标定。

所有被调参数、范围和使用的数据必须形成表格。湍流模型常数、流体密度、直径、长度、实测张力等不得作为自由校准参数。

### 6.2 项目级通过阈值

以下是本项目的预定工程验收阈值，不代表试验本身的置信区间：

- 主频相对误差中位数不超过 5%；
- 主导模态相差不超过 1 阶；
- spanwise RMS 曲率/位移包络的归一化 `L2` 误差不超过 20%；
- 最大 RMS 曲率/位移误差不超过 25%；
- 平均 IL 偏移的最大误差不超过 20%；
- 预测必须给出网格、时间步、切片数和统计窗敏感性，数值不确定度应小于模型间差异。

如果达不到阈值，不允许通过重新选择统计窗口或逐工况调阻尼“修正”。应判断误差来自二维水动力、流固时间耦合、结构模型、边界条件还是试验数据解释，并如实报告。

### 6.3 ANCF 价值判据

实验符合度更高不是唯一判据。ANCF 只有在低张力/大斜率区稳定地降低多个独立指标误差，且差异超过数值不确定度时，才能说它对该区间更有价值。若两模型在全部可验证工况内接近，应把结论写为“线性梁在已覆盖范围内足够”，并给出尚未覆盖的低张力外推范围，而不是人为制造优势。
