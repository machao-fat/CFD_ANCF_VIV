# Ur=5.2 时间步后处理修复

原 `compare_dt.py` 对细步长结果使用了固定 `0.0025 s` 的抽样条件。该逻辑把细步长时间数组强行截取到粗步长网格，且用等权算术平均代替了物理时间积分，因此不是两个独立时间积分网格上的同一统计量。

现已改为：

- 两个案例分别使用完整的 5–10 s 窗口；
- 显式检查时间数组单调性和窗口端点；
- RMS 按各自完整网格计算；
- 平均功率按各自时间数组进行梯形积分后除以窗口长度；
- 不再使用 `round((time-window_start)/0.0025) % 2` 抽样；
- 增加时间数组对齐和人工正弦回归测试，2/2 通过。

修正结果：

| 指标 | 修正值 |
|---|---:|
| 位移 RMS 相对变化 | 0.4603% |
| `Fy` RMS 相对变化 | 0.5791% |
| 平均功率相对变化 | 1.1764% |
| 粗步长样本数 | 2001 |
| 细步长样本数 | 4001 |

因此短窗时间步筛查通过；这不等同于长时间 VIV 稳态收敛，后者仍需用至少 10 个稳定周期复核。
