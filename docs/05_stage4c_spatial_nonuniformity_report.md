# Stage 4C-A 空间非均匀载荷与 H/H^T 映射报告

## 方法与边界

本报告使用合成二维单位跨距力 `f_i^(2D) [N/m]`，不读取真实 CFD。结构切片力由正式 `LoadRecord.from_conversion` 生成：

```text
F_i [N] = f_i^(2D) [N/m] × slice_length_m [m]
Q = Σ H_i^T F_i
```

`unit_span_m=1.0 m`，`R_GL=I`，`coupling_iteration=0`，所有输入有限。合成随机 profile 的 seed 写入结果，主报告使用 seed `20260810`；虚功审计使用 `random_seed=17`（3-slice）和 `19`（5-slice）。

## 载荷设计

- uniform：`(fx,fy,fz)=(2.0,-1.0,0.5) N/m`。
- linear：`fx=1.2+0.35s`，`fy=-0.8+0.22s`，`fz=0.1-0.015s`，单位均为 N/m。
- non_monotonic：`fx=1+0.65 sin(0.73s+0.17)`，`fy=-0.4+0.9 cos(0.91s-0.23)`，`fz=0.15+0.12 sin(1.37s+0.4)`，单位均为 N/m。
- random：每个 slice 独立、由 seed 20260810 复现；完整数据保存在 `spatial_load_mapping_summary.json`。

下表写出各切片的 `f^(2D)` 和积分总力 `F`，分量顺序均为 `(x,y,z)`。

## 映射、非节点插值与审计

使用正式 `build_H_for_manifest`，网格节点为 `(0,3,6.5,10) m`；3-slice 和 5-slice 中心均不要求与节点重合。使用正式 `map_integrated_slice_forces`，没有复制 H/H^T 或 hash 实现。输入切片顺序反转后，所有 profile 的广义力完全一致。

所有 profile 的 `Δs` 审计均为：unit force 单位 N/m、`F_i=f_i^(2D)Δs_i` 恰好一次、mapping 不再乘 `slice_length_m`。删除任一切片时，正式 mapping 的 slice ID 完整性检查拒绝不完整事务。

三、五切片全部 profile 的最大虚功误差为：

```text
max(error_rel) = 1.11022302462516e-16
max(error_abs) = 1.11022302462516e-16 J
threshold       = 1e-12
```
