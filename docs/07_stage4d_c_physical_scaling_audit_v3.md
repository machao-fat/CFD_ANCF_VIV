# Stage 4D-C-A-v3 VIV 物理尺度离线审计

## 1. 工程基准与 VIV 物理基准分离

当前模型可以作为工程耦合软件基准：它能够用于检查 H/H^T 映射、checkpoint、restart、进程控制、有限性和短时事务稳定性。但当前结构频率与充分发展圆柱流场脱涡频率不在同一物理尺度，不能作为锁定区或长期 VIV 物理基准。

## 3. 质量和刚度尺度

按当前 `D=1 m`、`dInner=0.9 m`、钢材密度 `7850 kg/m³`：

- 结构单位长度质量：`1171.4213607 kg/m`
- 排水质量单位长度（ρ=1000）：`785.3981634 kg/m`
- 排水质量单位长度（模型流体ρ=1025）：`805.0331175 kg/m`
- 不含附加质量的质量比（ρ=1000）：`1.4915`
- 不含附加质量的质量比（ρ=1025）：`1.45512`
- 附加质量：当前模型未包含
- 轴向刚度 `EA`：`3.0889709766e10 N`
- 弯曲刚度 `EI`：`3.4943984173e9 N·m²`
- 顶张力：`1.0e7 N`

质量比只是无附加质量候选值，不能替代带有流体附加质量和阻尼依据的物理模型识别。

## 4. 目标 VIV 频率尺度

在 `D=1 m` 下，若要求第一结构频率对应 `Ur=3–10`，目标频率范围为：

| 工况 | 目标第一结构频率范围 (Hz) |
|---|---:|
| Re80, U=0.8 | `0.08–0.2667` |
| Re100, U=1.0 | `0.10–0.3333` |
| Re120, U=1.2 | `0.12–0.4000` |

当前第一频率 `27.608 Hz` 比这些目标范围高约两个数量级。要进入同一物理尺度，必须重新冻结结构质量、张力、刚度、尺度或附加质量/阻尼参数，并以新的验证证据建立 VIV 物理基准。本任务不修改这些参数。

## 5. 路线建议

1. 不建议立即启动更细真实 release CFD。当前已有最细步对工程带宽中的 302.9 Hz 模态仍有约 `-13.3 rad` 的 0.25 s 理论相位误差；达到 `0.05 rad` 需要理论 `dt≈1.8661e-5 s`，约 13,397 个全局步、40,191 次三切片 OpenFOAM 执行，成本显著增加，且 v2 与严格时间戳对齐定义尚需 Sol 冻结。
2. 不建议继续 preload。v2 已确认它改变静力参考构型，且最细相邻对切片速度 NRMSE 约 `0.6075`。
3. 可以把 generalized-α/HHT 作为高频数值耗散方法候选进行理论设计，但本任务没有实现。任何候选必须保持第一、第二低频模态的相位和能量精度，并以独立基准验证。
4. 物理阻尼只能在实验或文献依据后冻结；本任务没有选择 Rayleigh 系数。
5. 应优先重建新的 VIV 物理参数基准，并将“工程带宽收敛”和“VIV 物理收敛”作为两套独立 Gate 候选。

## 6. 结论

当前组合的正确身份是“工程耦合基准”，不是“VIV 物理验证基准”。任何后续锁定区、稳定振幅或长期能量结论，都必须等待新的物理尺度、阻尼依据、时间/结构离散和持续时间证据。
