# Stage 4E-A-v3：滤波稳健性审计

## 处理边界

公开仓库的 `main1.m` 可确认 0.01–20 Hz 的带通范围，但公开仓库没有 `bpass.m`。因此本报告只冻结“本项目试验处理协议”，不称为作者原滤波器的严格复现。

比较了：去趋势不带通、二阶/四阶/六阶零相位 0.01–20 Hz、四阶零相位 0.05–20 Hz、四阶零相位 0.10–15 Hz。

## 目标模态频率

| 处理 | CF1 | IL2 | IL4 |
|---|---:|---:|---:|
| 去趋势 | 1.5564 | 3.2959 | 6.6223 |
| 二阶 0.01–20 | 1.5564 | 3.2959 | 6.6223 |
| 四阶 0.01–20 | 1.5564 | 3.2959 | 6.6223 |
| 六阶 0.01–20 | 1.5564 | 3.2959 | 6.6223 |
| 四阶 0.05–20 | 1.5564 | 3.2959 | 6.6223 |
| 四阶 0.10–15 | 1.5564 | 3.2959 | 6.6223 |

目标模态身份在全部六种处理下保持一致。

## 模态位移 RMS 与幅值

CF mode 1 RMS 在 `6.811e-3–6.910e-3 m` 范围内；IL mode 2 RMS 在 `1.125e-3–1.397e-3 m`；IL mode 4 RMS 在 `8.102e-4–8.307e-4 m`。最大 A/D 受滤波幅值影响，但所有处理均保持 CF mode 1、IL modes 2/4 的身份。

## 协议冻结候选

选择四阶零相位 0.01–20 Hz，理由是：

1. 保留 `main1.m` 中可见的频带边界；
2. 位于二阶和六阶之间；
3. 三个目标模态频率在全部滤波方案中不变；
4. 明确标注为项目协议，而不是 `bpass.m` 精确复现。

该选择不构成真实 CFD 或试验验证通过。
