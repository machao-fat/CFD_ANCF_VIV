# Stage 4D-C-A-v3 Sol 主 Agent 复核

## 1. 最终判定

Stage 4D-C-A-v3 离线诊断范围通过，结论为 `diagnostic_passed_with_metric_correction`。这不等于 Stage 4D-C 时间步 Gate 通过。

主 Agent 决定：

1. 后续时间步对比只允许使用共同物理时刻严格匹配；
2. `0.000625/0.0003125 s` 最细回放对的正式切片速度 NRMSE 更正为 `0.08313202361922077`；
3. v2 的 `0.07126413802276343` 仅保留为历史追溯值，不再用于 Gate；
4. 将模态 1–7（最高约 `302.897 Hz`）记录为当前 `nElem=2` release 回放的“工程诊断有效带宽”，但不将其冻结为通用物理带宽，也不用它降低既有 5% Gate 阈值；
5. 不启动更细真实 release CFD；
6. 不继续 preload 路线；
7. 暂不修改生产 Newmark 积分器，不实施 generalized-α/HHT；
8. 优先进入公开柔性管 VIV 试验基准选择和物理参数重建阶段。

## 2. 证据复核

- 协议 `0.2.1` 和 manifest hash 一致。
- `nElem=2` 自动识别 13 个自由 DOF，保留 13 个有限模态。
- M 正交最大残差 `6.66e-16`，K 对角化相对残差 `7.24e-16`。
- 全模态对 `q/qdot/qddot` 和 H 切片运动的最大相对重构误差约为 `6.32e-16`。
- 直接 `F·v`、`H^T` 广义力功率和全模态功率一致。
- 模态 1–2 主导位移和动能；模态 6–7 的动能占比很小，但约占 `4.85%` 绝对外力做功，且对切片速度有可见贡献。
- 剩余时间步误差不能全部归因于高阶模态；严格时间匹配后，前两阶模态相位差仍是最大影响项，模态 6–7 是次要影响项。
- 主 Agent 重跑专项测试 `9/9`、`compileall` 和全项目测试 `256/256`，均通过。

## 3. 时间匹配更正

v2 使用：

```python
idx = np.arange(0, len(fine["time_s"]), ratio)
```

但回放时间序列不包含 `t=0`，细步第一条状态位于 `t=dt_f`。因此 v2 实际将：

```text
fine:   dt_f, 3dt_f, 5dt_f, ...
coarse: 2dt_f, 4dt_f, 6dt_f, ...
```

进行了错位比较。v3 通过共同物理时刻匹配得到 `0.0831320`，该规则被冻结为后续唯一合法规则。

## 4. 不继续更细 CFD 的原因

当前有贡献的工程诊断带宽延伸至约 `302.897 Hz`。若要使该频率在 `0.25 s` 内的 Newmark 累积相位误差不超过 `0.05 rad`，理论时间步约为 `1.8661e-5 s`，需要约 13,397 个全局步、40,191 次三切片 OpenFOAM 执行。

与此同时，当前第一结构频率为 `27.608 Hz`，而流场脱落频率仅为 `0.107–0.178 Hz`，第一模态约化速度只有 `0.029–0.043`。即使完成高成本细时间步计算，也不能产生合理的 VIV 锁定或稳定振幅验证。

因此 Stage 4D-B 的工程耦合原型证据继续有效，但 Stage 4D-C 的这一参数分支不再追加真实 CFD 计算。
