# Stage 4D-C-A-v2 Sol 主 Agent 复核

## 1. 复核结论

Stage 4D-C-A-v2 的离线诊断实施范围完成，状态时间语义、Newmark 运动学关系、载荷回放来源和自动化测试证据有效。但本轮没有产生可供真实 CFD campaign 采用的相邻时间步对，因此：

- Stage 4D-C 时间步 Gate 仍不通过；
- 不选择 preload 路线；
- 暂不授权新的真实 OpenFOAM 细时间步计算；
- 下一步先完成与 `nElem=2` 一致的全模态参与度、带宽和物理尺度审计。

本结论为 `diagnostic_passed_but_no_real_dt_pair`，不是 Stage 4D-C Gate 通过。

## 2. 已确认证据

- 粗、细步的 staged/committed 状态时间语义一致，未发现固定半步或整步错位。
- Newmark 位移与速度运动学残差均在浮点精度量级。
- release 路线的载荷回放使用完整 `F(t)`；preload 路线使用静态 `F(0)` 与动态 `F(t)-F(0)`，未发现初始力重复施加。
- release 的 `0.000625/0.0003125 s` 相邻对位移 NRMSE 为 `0.0087399`，前三阶模态速度和加速度 NRMSE 分别为 `0.0140484` 和 `0.0182960`，但切片速度 NRMSE 仍为 `0.0712641`，超过 5% 门槛。
- preload 的最细相邻对切片速度 NRMSE 为 `0.607466`，且改变了静力参考构型，没有证据表明它能解决当前 Gate 问题。
- 主 Agent 重跑专项测试 `7/7` 和全项目测试 `247/247`，全部通过；`compileall` 通过。

## 3. 必须修正的证据问题

现有回放使用 `nElem=2`，相应线性化模态前三阶为：

```text
27.6080461424 Hz
27.6080461424 Hz
120.7284392350 Hz
```

现有 `newmark_dispersion_audit.json` 却使用了 `nElem=4` 的 `27.5093457558 Hz` 和 `109.2685459870 Hz`。这不影响“高频 Newmark 相位色散显著”的定性判断，但不能作为 `nElem=2` 回放的定量 Gate 证据。下一轮必须使用与回放完全一致的质量矩阵、切线刚度和约束自由度重建全模态审计。

`nElem=2` 的独立频谱复算还显示 `128.4403 Hz`、`302.8969 Hz` 及更高频率。在 `dt=0.0003125 s` 时，`120.7284 Hz` 仅约有 `26.51` 步/周期，在 `0.25 s` 内的解析 Newmark 累积相位误差约为 `-0.881 rad`。因此，直接再缩小真实 CFD 时间步会显著增加成本，但仍未回答这些高频分量对切片速度、结构能量和 CFD 做功是否重要。

## 4. 物理尺度警告

当前 `L=10 m, D=1 m, E=2.07e11 Pa, T=1e7 N, nElem=2` 模型的第一结构频率约为 `27.608 Hz`，而三组发展流场的脱落频率约为 `0.1073–0.1783 Hz`。相应：

- 结构频率/脱落频率约为 `155–257`；
- 以 `U/(f_n D)` 定义的约化速度仅为 `0.0290、0.0362、0.0435`。

因此，当前组合可用于考核耦合软件的工程稳定性，但不是一个可用于锁定区或长时 VIV 物理验证的参数组合。后续必须明确分离：

1. “工程耦合基准”：审计接口、守恒、restart 和数值稳定性；
2. “VIV 物理基准”：重新冻结能使低阶结构频率与流致频率处于同一尺度的参数，并引入有依据的阻尼和验证数据。

## 5. 下一步决定

进入 Stage 4D-C-A-v3 离线审计，不运行新 OpenFOAM，不修改 ANCF 生产积分器，不加入无依据的 Rayleigh 阻尼。v3 必须：

- 使用与 `nElem=2` 回放完全一致的全模态基；
- 将位移、速度、加速度、动能、应变能和外力做功分解到全部模态；
- 证明切片速度 7.13% 误差的主要模态和频带；
- 判断最细相邻对是否已在具有实际位移/做功贡献的频带内收敛；
- 量化当前工程基准与 VIV 物理基准的频率尺度不匹配；
- 最后只能在“继续更细 release”、“设计高频数值耗散方法候选”、“等待阻尼数据”、“先重建 VIV 物理参数基准”中给出证据化建议，不得自行启动真实 CFD。
