# Euler–Bernoulli 梁对照模型与验证

## 1. 适用范围和边界

该分支是 ANCF 的小位移、小转角对照模型，不是真实大变形真值。它不引入完整 Green 应变、轴向自由度或动态几何更新；轴向预张力只以冻结的几何刚度进入横向线性方程。两个横向平面相互独立：流向平面为 `u` 及转角，横流平面为 `v` 及转角。

每个节点的全局顺序为：

```text
[u, theta_u, v, theta_v]
```

底端和顶端的 `u`、`v` 位置约束为零；两端斜率/转角均自由。这与当前 ANCF 的横向位置约束相同，不额外施加夹持或简支转角条件。EB 分支的 `z_m` 保持为参考弧长，非零轴向载荷不作为横向自由度输入。

## 2. 单元公式

对长度 `Le` 的两节点单元，令 `xi=x/Le`，Hermite 形函数为：

```text
N1 = 1 - 3xi^2 + 2xi^3
N2 = Le (xi - 2xi^2 + xi^3)
N3 = 3xi^2 - 2xi^3
N4 = Le (-xi^2 + xi^3)
```

单平面位移为 `w(x)=N(x) q_e`。一致质量和弯曲刚度采用高斯积分：

```text
M_e = integral(rho A N^T N dx)
K_b,e = integral(EI N_,xx^T N_,xx dx)
```

冻结预张力 `T0(s)` 的几何刚度为：

```text
K_g,e = integral(T0(s) N_,x^T N_,x dx)
```

均布载荷按同一形函数做一致结点载荷：

```text
Q_e = integral(N^T p dx)
```

全局矩阵为 `K=K_b+K_g`，阻尼为 `C=alpha M+beta K`。切片总力不转换成均布线载荷，而是通过已有参考位置形函数构造 `H`，用 `Q_CFD=H^T F_slice` 施加到对应横向平面。

## 3. 预张力模式

默认 `pretension_mode='ancf_initial_balance'`，从底端到顶端使用与 ANCF 初始平衡一致的有效浸没重度：

```text
T0(s) = T_top - w_sub (L-s)
```

另保留 `pretension_mode='paper_formula'`，用于复现论文式 `T(z)` 分布并量化差异。两种模式都冻结在结构线性化矩阵中，不随动态几何更新。

## 4. Newmark 推进

使用平均加速度参数 `beta=1/4, gamma=1/2`。在每一步先形成位移和速度预测量，再解：

```text
K_eff = K + a0 M + a1 C
```

并在自由自由度上求解，约束位置直接回写。步后检查自由自由度残差、位移/速度/加速度有限性、结构动能、弯曲能、预张力能和阻尼功。

## 5. 独立验证结果

测试入口为 `tests/structure_eb_fem/test_eb_fem_verification.m`，汇总为 `results/04_eb_fem_verification/eb_fem_verification_summary.json`。

| 检查 | 结果 |
|---|---:|
| 均布载荷解析解最大采样相对误差 | `7.788e-4` |
| 均布载荷节点值误差 | `3.79e-19` |
| 集中载荷最细网格误差 | `5.202e-6` |
| 预张力固有频率相对误差 | `8.722e-7` |
| Newmark 两时间步位移差 | `1.938e-5` |
| 无阻尼自由振动能量漂移 | `7.128e-14` |
| EB/ANCF 共享 `H/H^T` 虚功相对误差 | `0` |
| 小载荷静态位移绝对差 | `9.826e-12 m` |
| 小载荷相对位移差 | `6.213e-5` |
| 小载荷首阶频率最近邻差异 | `3.108e-5 Hz` |

同时复跑阶段一 ANCF 检查后，刚体模态、轴向一致性、质量矩阵对称性、低张力收敛和网格/时间步收敛均保持通过。此前发现的切片力分量交错顺序已在 ANCF 和 EB 的外载荷映射中显式修正为：

```text
[Fx_1,Fy_1,Fz_1,Fx_2,Fy_2,Fz_2,...]^T
```

因此，小载荷不一致不再由 `reshape` 的行列主序错误造成。

## 6. 验证结论

独立 EB 验证通过，小变形一致性达到当前准入阈值。该结论只说明两结构分支在相同质量、刚度、预张力、阻尼、边界和切片传力下具有可比性；不把 EB 模型提升为 ANCF 大变形解，也不替代后续真实自由耦合验证。
