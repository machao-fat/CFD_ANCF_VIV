# Stage 4F-C 分区强耦合三切片预检 Gate 报告

## 结论

本阶段终态为 `failure_terminal_physical_step_1_iteration_0_frozen_Cd_gate`，Gate 不通过。未进入五/九切片、长时 VIV、锁定区或实验对比。

## 冻结算法

- `dt=0.000625 s`
- 固定松弛 `alpha=0.5`
- 最多 12 次候选迭代
- 力残差分母为 `max(25000 N, ||F_observed||inf, ||F_relaxed||inf)`
- 相对残差不超过 `1e-3`，绝对残差不超过 `25 N`，连续两次满足才允许提升
- 每个候选从同一个物理步父 checkpoint 回滚
- 非选中候选不生成 checkpoint；每个物理步最多提升一个 unified committed checkpoint
