# Stage 4E-A-v3.1 稳健切片冻结报告

## 零交叉

数字化剖面的线性零交叉位于 `s0/L=0.474290780141844`，即 `s0=3.6235815603 m`。v3 当前优化 5 切片的区间 `[0.3390813, 0.5392507]` 包含该零点，因此不能冻结。v3.1 约束优化固定零交叉为一个切片边界、保持五个正长度、完整覆盖立管且无重叠/间隙。

约束候选为：

`[0, 0.1332702821, 0.3065492222, 0.4742907801, 0.7454404474, 1]`

长度为 `[1.01818, 1.32385, 1.28155, 2.07158, 1.94483] m`，五片局部速度符号为 `+,+,+,-,-`，零点恰为边界，没有切片跨越零点。

## 全局与模态加权误差

参考积分包含 `∫|U|ds`、`∫U²ds`、`∫U|U|ds`，并对 m=1、2、4 计算 `Q_m,drag` 与 `Q_m,magnitude`。切片长度只乘一次。零交叉约束候选的全局相对误差为：

| 量 | 相对误差 |
|---|---:|
| ∫U ds | 1.4813% |
| ∫|U| ds | 2.7707% |
| ∫U² ds | 0.2017% |
| ∫U|U| ds | 1.1079% |
| m=1/2/4 模态加权归一化绝对误差最大值 | 3.2320% |

虽然模态误差满足 5% 建议值，`∫|U|` 超过 2% 正式阈值，因此该零交叉候选不能冻结。均匀 7、均匀 9 的名义积分/模态误差可接受，但两者都没有把名义零点设为边界，故不能替代零交叉约束的正式冻结要求。

## 速度剖面不确定性

采用速度点 ±25 mm/s、深度位置 ±0.015、固定随机种子 20260812 的 1000 组 Monte Carlo。线性插值与 PCHIP 形状保持插值都使用固定候选边界，不在样本中重新优化。

名义零交叉范围：线性 `[0.457981, 0.490498]`，PCHIP `[0.458150, 0.490782]`。所有候选的切片中心方向分类在样本中均未改变。

关键 p95（全局最大误差 / 模态归一化最大误差）如下：

| 候选 | 线性 | PCHIP |
|---|---:|---:|
| v3 当前优化 5 | 3.0504% / 15.5942% | 3.7967% / 15.3244% |
| 均匀 7 | 1.8506% / 6.5563% | 2.1286% / 10.2749% |
| 均匀 9 | 1.4305% / 2.3583% | 2.2444% / 4.3143% |
| 零交叉约束 5 | 4.2129% / 7.7282% | 4.0587% / 10.3867% |

这些稳健性结果不改变零交叉边界和正式 H 证据的缺口；因此最终建议为 `no_scheme_frozen`，不是把均匀 7/9 误写成满足零交叉冻结条件。

## 范围结论

本报告只完成离线剖面积分、模态加权载荷代理和不确定性审计。没有真实五切片 CFD，没有修改 OpenFOAM 算例，也没有进行幅值严格试验验证或锁定区判断。
