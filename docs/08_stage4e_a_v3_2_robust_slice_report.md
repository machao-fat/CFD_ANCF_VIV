# Stage 4E-A-v3.2：7/9 切片候选与稳健性

## 计算边界

本报告使用数字化速度剖面、线性插值和 PCHIP 插值做离线中点求积。速度不确定性为 ±25 mm/s，归一化深度节点不确定性为 ±0.015，固定随机种子 `20260812`，共 1000 组样本。每个候选边界在全部样本中固定，不在样本内重新优化。`slice_length_m` 只乘一次。

名义零交叉为 `s/L=0.474290780141844`，即 `s=3.623581560283688 m`。7/9 候选同时保留点采样和 inactive 零流缓冲两类语义。

## 稳健冻结解释

零交叉感知 7 点采样候选的边界为：

`[0, 0.123694903, 0.303090633, 0.474290780, 0.612537816, 0.764749554, 0.876547994, 1]`。

其中心为 `[0.472515, 1.630321, 2.969597, 4.151685, 5.261238, 6.269757, 7.168413] m`，中心方向为 `+++----`。1000 组线性和 PCHIP 样本中方向变化次数均为 0；零交叉范围为 `[0.456742537, 0.491948879]`。该候选允许代表区间跨越零点，但中心符号稳定，且中点求积误差满足标准。

因此按“优先满足标准的 7 切片”规则，推荐冻结离线候选为 `zero_crossing_aware_7_point_sampling`。这只是 7 切片数值积分与协议设计候选，不是已完成的真实 7 切片 CFD。

该候选的具体边界、中心、长度、速度、全局积分和 m=1/2/4 模态加权结果已逐字段写入 `seven_nine_slice_candidates.json`；线性与 PCHIP 的 1000 组统计逐候选写入 `seven_nine_uncertainty.json`。

零流缓冲 7 切片覆盖了 `[0.45,0.50]` 的名义不确定零点区间，inactive 切片不等待 CFD ready，但在线性 p95 全局误差为 6.784%，不满足 p95≤5%，所以不推荐作为当前冻结方案。该失败结果被保留。

## 模态加权误差

所有候选均输出：

`Q_m,drag = ∫phi_m U|U| ds` 和 `Q_m,magnitude = ∫phi_m U² ds`，其中 `m=1,2,4`，并同时保存 signed relative error 和以 `max(|Q_ref|,0.05∫|phi f|ds)` 为分母的 normalized absolute error。未使用只优化全局积分的替代判据。

## 物理含义

二维切片在本分析中是轴向采样点，`slice_length_m` 是数值积分权重，不是内部速度必须均匀的三维有限厚度 CFD 体。因此“积分区间覆盖零点”本身不自动失败；判定依据是中心方向稳健性和全局/模态误差。若未来采用 inactive 缓冲，则必须把缓冲区漏掉的水动力误差显式计入，本报告已做该对照。
