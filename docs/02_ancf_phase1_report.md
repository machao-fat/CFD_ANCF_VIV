## 3. 结构模型冻结定义

### 3.1 坐标、自由度和边界

- 全局右手坐标：`+z`沿立管由底端指向顶端；`+x`为顺流方向；`+y`为横流方向。
- 参考弧长：`s=0`在底端，`s=L`在顶端。
- 每个节点六个自由度：

```text
[r_x,r_y,r_z,r_{s,x},r_{s,y},r_{s,z}]
```

- 底端：三维位置固定。
- 顶端：`x/y`位置导向固定，`z`方向施加顶张力；这是当前直立TTR MVP的边界，不代表完整平台运动边界。

### 3.2 能量和内力

中心线采用两节点三次Hermite ANCF插值：

```text
r_e(ξ) = S(ξ) q_e,       0 <= ξ <= 1
```

其中`q_e`包含两端位置和斜率。定义

```text
a = ∂r/∂s,       b = ∂²r/∂s²
ε = 1/2 (a·a - 1)
κ² = |a × b|² / |a|⁶
```

单元弹性能采用

```text
U_e = ∫ [ 1/2 EA ε² + 1/2 EI κ² ] ds
```

内力为`Q_e = ∂U_e/∂q_e`，切线为`K_e = ∂²U_e/∂q_e²`。实现使用解析能量导数并在装配后显式对称化；不依赖旧程序生成的Symbolic Math Toolbox文件。

### 3.3 质量、外载荷和时间推进

- 质量矩阵：五点Gauss积分得到一致质量矩阵。
- 外载荷：重力、排水浮力、顶端轴向力和切片外力。
- 时间积分：Newmark平均加速度格式`β=1/4, γ=1/2`，每一步使用Newton迭代。
- 当前矩阵为教学/验证规模的稠密矩阵；大规模模型进入CFD后需要稀疏装配和线性求解器优化。

## 4. CFD切片接口

切片中心线运动由

```text
x_slice = H3 q_structure
```

给出，其中`H3`把结构自由度映射为每个切片的`[x,y,z]`位置/速度/加速度。每个切片的流体合力使用全局坐标三分量、集成力单位N：

```text
F_slice = [Fx_N, Fy_N, Fz_N]^T
Q_structure = H3^T F_slice
```

因此离散虚功严格满足

```text
δW = (H3 δq)^T F_slice = δq^T H3^T F_slice
```

切片CSV包括`schema_version, step, coupling_iteration, time_s, slice_id, s_ref_m`以及位置、速度、加速度字段；载荷CSV包括相同时间元数据、`s_ref_m`和`force_x_N/force_y_N/force_z_N`。读写均检查行数、切片弧长、有限性、切片顺序和时间元数据一致性。运动CSV使用原子临时文件替换，载荷文件不接受NaN/Inf。

MAT检查点保存完整结构状态，支持下一步重启；这为后续强耦合迭代的回滚提供了最小可用基础。

## 6. 旧程序包的接力判断

旧包路径为`...\ANCF\Run4v4_wuzfv2\Run4v4_wu`，共检查到111个文件，其中70个MATLAB文件和大量结果CSV。旧程序核心是面向海床/触地点、波流、平台运动和尾流振子的复杂海洋立管模型，不是直立顶张式二维切片耦合器。

### 可以直接接力的部分

- 两节点Hermite ANCF形函数和六自由度节点组织；
- Green轴向应变与曲率能量的物理思想；
- 一致质量矩阵、Newton/Newmark求解框架；
- Morison载荷和分段材料参数的组织方式；
- 结果输出中位移、曲率、应变、张力的字段思路。

### 已经改写或必须改写的部分

- 原`mass_matrix.m`按`zeros(Riser.Nne)`起始并动态扩展，最小单元测试会越界；新实现预分配完整`ndof×ndof`矩阵。
- 原`PostTension2.m`存在单位和方向耦合风险；新实现同时输出Green应变、材料轴力`EAε`和沿当前切线投影的物理张力。
- 原程序的海床、触地点、波流、平台运动、尾流振子和分段复杂边界没有带入主线。
- 原程序没有OpenFOAM引用、没有显式`H/H^T`接口、没有按时间步接收切片载荷、没有标准checkpoint/rollback，也没有线性Euler–Bernoulli适配器。

旧包没有发现独立`LICENSE`或明确开源授权文件，只有代码注释中的引用/致谢要求。因此本项目只读取、运行和比较其算法思想；不复制、重新发布或把旧代码包装成新项目代码。原始文件保持不变。

## 8. 进入阶段二的条件

可以进入阶段二，但必须先冻结以下四项：

1. 安装并固定OpenFOAM版本，先完成静止圆柱和规定横向运动圆柱的单切片基准；
2. 实现传统Euler–Bernoulli梁适配器，并确保与ANCF共享同一`slice_loads.csv`；
3. 确认主要公开试验（优先Chaplin/Southampton阶梯流或同等可获取数据）的合法下载路径、参数和测量量；
4. 将当前稠密结构矩阵改为稀疏装配，并在CFD时间步下重新做网格、时间步和Newton容差标定。

阶段二的核心科学问题保持为：

> 在低张力和明显几何非线性条件下，传统线性梁模型与CFD–ANCF预测结果何时产生不可忽略的差异？

当前阶段已经具备回答该问题所需的ANCF结构基线，但还没有流体载荷和实验验证，因此不能提前宣称ANCF在VIV预测中优于传统梁。
