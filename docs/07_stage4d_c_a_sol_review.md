# Stage 4D-C-A Sol主Agent复核

日期：2026-08-11  
决定：`failed_at_time_step_subgate`

## 结论

Stage 4D-C-A 当前不通过。候选模板与 `dt=0.00125 s` 真实三切片运行证据有效，但粗细时间步的动态时程没有收敛，因此不得开始 nElem=4/8、选定配置 restart 或 1 s 分级延时。

允许的下一步仅为 Stage 4D-C-A-v2 的结构时间积分、状态语义和初始化瞬态诊断；在主Agent再次授权前不得启动更细时间步真实 OpenFOAM campaign。

## 独立证据复核

- 细时间步运行完成200/200个全局步和600/600个真实OpenFOAM切片执行。
- 600份日志全部正常结束，排除标准 `FOAM_SIGFPE` trapping提示后没有Fatal、NaN/Inf或异常终止。
- 原始日志重算最大CFL为 `0.086281397650671`。
- 200个committed checkpoint的5200个引用对象重新计算大小和SHA-256，错误数为0。
- MATLAB启动次数为1；launcher PID为 `10268`，协议worker PID为 `35240`。
- 专项测试6/6、全项目240/240、compileall均通过。

## 时间步问题复核

1. 粗步 `dt=0.0025 s` 与细步 `dt=0.00125 s` 的对齐规则正确：粗步时刻与细步 `2k+1` 记录严格同一物理时间。
2. 两组状态均满足Newmark平均加速度法位移—速度梯形关系，最大残差分别约 `3.39e-21` 和 `5.08e-21`，没有发现简单的q/qdot时间标签错位。
3. 当前报告中的全q向量NRMSE `6.77e-7`被静态轴向坐标和约束自由度主导，不能作为动态位移收敛证据。
4. 扣除初始静态构型并仅比较动态横向自由度后，q动态NRMSE为 `0.2136954759853776`。
5. 三个切片的位移时程NRMSE约 `0.211–0.217`，速度时程NRMSE约 `0.376–0.403`；原比较程序只将位移RMS/峰值和速度RMS纳入Gate，漏掉了这些明显的时程差异。
6. qdot总体NRMSE为 `0.3908521876924054`，qddot总体NRMSE为 `1.0941190222479935`，失败结论成立。
7. 粗细步的qdot/qddot主频均约28 Hz，与线性化第一结构频率约27.51 Hz一致。最佳时间平移从前段约一个细步逐渐变化到末段约三个细步，表现为随时间累积的数值相位漂移，不是固定时间戳偏移。
8. 现有初始化使用零Rayleigh阻尼，并在静力初始化中把 `external_slice_force_N`强制置零；随后在耦合开始时突然施加充分发展流场水动力。这是激发27.5 Hz启动振铃的高度可疑来源，但仍需结构回放和初始化对照才能正式定因。

## 下一步边界

- 不降低5%阈值。
- 不把RMS/峰值接近解释为时程收敛。
- 不立即启动dt/4或dt/8真实CFD。
- 不开始nElem=4/8、restart或1 s延时。
- 先完成状态语义、动态度量、Newmark色散、结构载荷回放及静态水动力预载可行性审计，再由Sol选择下一组真实CFD时间步。
